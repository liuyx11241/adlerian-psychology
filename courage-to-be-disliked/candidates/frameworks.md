- id: f01
  title: 目的论归因框架
  type: framework
  source_chapter: 第一夜 我们的不幸是谁的错？
  source_quote: |
    "如果一味地关注过去的原因，企图仅仅靠原因去解释事物，那就会陷入'决定论'。阿德勒心理学考虑的不是过去的'原因'，而是现在的'目的'。"
  summary: |
    面对不良现状或心理困扰时，不采用“因为过去发生了X，所以我现在Y”的原因论，而是采用“为了达到目的Z，我制造了现在的状态Y”的目的论。通过这种逆向归因，打破过去决定论的束缚，找回行为和改变的控制权。
  tags: [mental-model, problem-solving, teleology]

- id: f02
  title: 外部因果律识别法
  type: framework
  source_chapter: 第二夜 一切烦恼都来自人际关系
  source_quote: |
    "将原本没有任何因果关系的事情解释成似乎有重大因果关系一样。例如，'我因为学历低所以无法成功'，这是一种自卑情结。"
  summary: |
    一种用于诊断和识别“人生谎言（借口）”的推理方法。当发现主张“因为有客观条件A，所以做不到B”时，识别这是否是将无关事物强行建立因果联系。其背后的真实目的往往是“为了回避做B的风险或努力，所以拿A当挡箭牌”。
  tags: [reasoning, cognitive-bias, self-deception]

- id: f03
  title: 课题分离矩阵
  type: framework
  source_chapter: 第三夜 让干涉你生活的人见鬼去
  source_quote: |
    "辨别究竟是谁的课题的方法非常简单，只需要考虑一下'某种选择所带来的结果最终要由谁来承担？'不干涉他人的课题，也不让别人干涉自己的课题。"
  summary: |
    处理人际关系纠纷和内耗的决策框架。面对一项任务或矛盾，先问“该选择带来的后果最终由谁承担？”来界定这是谁的课题。明确边界后，坚决不干涉他人的课题（即使出于善意），同时拒绝他人干涉自己的课题，从而砍断羁绊。
  tags: [decision, relationships, separation-of-tasks]

- id: f04
  title: 倾听更大共同体原则
  type: framework
  source_chapter: 第四夜 要有被讨厌的勇气
  source_quote: |
    "当我们在人际关系中遇到困难或者看不到出口的时候，首先应该考虑的是'倾听更大共同体的声音'这一原则。不要用学校这个共同体的常识来判断事物，而要遵从更大共同体的常识。"
  summary: |
    在局部环境（如学校、公司、原生家庭）遭遇人际困境或霸凌时的决策框架。不要被当前小共同体的权威和规则所PUA，而应将视角拉升到更大的共同体（人类社会整体）。用更大共同体的平等常识来审视眼前的压迫，从而获得正面拒绝或主动脱离的勇气。
  tags: [decision, problem-solving, perspective-shift]

- id: f05
  title: 横向关系与鼓励法
  type: framework
  source_chapter: 第四夜 要有被讨厌的勇气
  source_quote: |
    "阿德勒心理学反对一切'纵向关系'，提倡把所有的人际关系都看作'横向关系'。既不表扬也不批评，阿德勒心理学把这种基于横向关系的援助称为'鼓励'。"
  summary: |
    教育、管理或合作中的行为引导模型。放弃使用纵向的“表扬”与“批评”（两者的本质都是上位者对下位者的操纵与评价），转而建立“虽不同但平等”的横向关系。用纯粹的感谢（如“谢谢”、“帮大忙了”）进行“鼓励”，帮助对方找回面对人生课题的勇气。
  tags: [framework, leadership, horizontal-relationship]

- id: f06
  title: 存在标准评价模型
  type: framework
  source_chapter: 第四夜 要有被讨厌的勇气
  source_quote: |
    "请不要用'行为'标准而是用'存在'标准去看待他人；不要用他人'做了什么'去判断，而应对其存在本身表示喜悦和感谢。"
  summary: |
    评价自己或他人价值的思维模型。不采用“理想形象减法”或“行为标准（能做什么、创造了多少业绩）”来扣分，而是从“零起点”出发，以“存在标准（仅仅是平安活着存在于此，就值得感激和喜悦）”来接纳真实的自我与他人。
  tags: [mental-model, evaluation, self-acceptance]

- id: f07
  title: 幸福三位一体闭环
  type: framework
  source_chapter: 第五夜 认真的人生“活在当下”
  source_quote: |
    "把对自己的执著转换成对他人的关心，建立起共同体感觉。这需要从以下三点做起：'自我接纳'、'他者信赖'和'他者贡献'。"
  summary: |
    实现归属感与幸福的结构化路径。首先做到“自我接纳”（接受做不到的自己，改变能改变的）；在此基础上不惧背叛地做到“他者信赖”（无条件相信他人，视其为伙伴）；进而自然产生“他者贡献”（不需要自我牺牲，只要主观感到“我对他人有用”）。贡献感又反哺自我接纳，三者缺一不可形成闭环。
  tags: [framework, happiness, community-feeling]

- id: f08
  title: 现实性人生决策模型
  type: framework
  source_chapter: 第五夜 认真的人生“活在当下”
  source_quote: |
    "人生是连续的刹那。如果把强烈的聚光灯对准'此时此刻'，那就会既看不到过去也看不到未来。现实性运动是一种'当下做了当下即完成'的运动。"
  summary: |
    面对人生规划和目标设定时的思维模型。不把人生看作从起点到终点（山顶）的“线”（潜在性运动），而是看作连续的刹那（点）。把过程本身视为结果，打强烈聚光灯于“此时此刻”。只要认真过好当下每一个刹那（跳好当下的舞），人生在任何节点都是完结且圆满的。
  tags: [decision, mental-model, present-moment]

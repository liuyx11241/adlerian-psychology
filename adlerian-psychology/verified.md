# Verified Methodological Units (阶段 1.5 产出)

通过整合 `frameworks.md` 和 `principles.md`，以下 5 个核心方法论单元通过了三重验证，将进入阶段 2，被转化为独立的可执行 Skill。

---

- id: s01
  title: 课题分离矩阵 (Separation of Tasks)
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 亲子关系场景：父母逼迫孩子学习
      - 职场关系场景：面对上司的无理指责
      - 自我心理场景：青年害怕被别人讨厌
  V2_predictive_power:
    passed: true
    novel_question: "如果伴侣沉迷工作不顾家，我该怎么办？"
    derived_answer: "区分课题。伴侣如何分配精力是他/她的课题，你无权强行改变；你的课题是如何表达你的感受以及是否选择继续这段关系。专注自己的课题。"
  V3_exclusivity:
    passed: true
    why_not_common: "常识认为'因为关心所以要干涉'，阿德勒认为'一切烦恼皆因干涉课题'，即使出于善意也不行，这是高度反常识和反直觉的界限法则。"

- id: s02
  title: 目的论重构 (Teleological Reframing)
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 心理创伤场景：朋友闭门不出
      - 情绪失控场景：在咖啡馆因为衣服被弄脏而对服务员发火
      - 情感回避场景：女学生患上脸红恐惧症以回避告白失败
  V2_predictive_power:
    passed: true
    novel_question: "为什么我总是重度拖延症？"
    derived_answer: "不是因为你天生懒惰（原因论），而是你内心深处有着'保留可能性'的目的——只要不去做，就可以安慰自己'如果我全力以赴肯定能行'（目的论）。"
  V3_exclusivity:
    passed: true
    why_not_common: "彻底否定了目前主流的弗洛伊德精神分析（决定论/创伤论），主张情绪和症状都是我们为了当下目的而主动制造的'工具'。"

- id: s03
  title: 横向沟通法 (Horizontal Feedback Loop)
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 教育场景：孩子帮忙做家务时父母的反馈
      - 职场场景：与公司上司的意见分歧
      - 心理辅导场景：哲人与青年的对话地位
  V2_predictive_power:
    passed: true
    novel_question: "新来的实习生独立解决了一个难题，我该如何反馈？"
    derived_answer: "绝对不能说'干得好'或'你真棒'（这是一种纵向的居高临下的评价），而应该说'谢谢你，帮了大忙'或'我很高兴'（横向的鼓励与存在价值感谢）。"
  V3_exclusivity:
    passed: true
    why_not_common: "常识认为'表扬'是积极的教育和管理手段，但阿德勒犀利指出表扬的本质是'有能力者对无能力者的操纵'，具有强烈颠覆性。"

- id: s04
  title: 刹那舞步 (The Dancing Present)
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 生涯规划场景：想成为小提琴手但未能如愿的人
      - 旅行场景：旅行的目的不是到达目的地，而是走出家门的那一刻
      - 哲人自身场景：没有明确目标，只是在当下学习希腊哲学
  V2_predictive_power:
    passed: true
    novel_question: "如果我现在做的工作很痛苦，但为了三年后的升职，我要忍耐吗？"
    derived_answer: "不要忍耐。人生不是一条通往未来的线，而是连续的点。根本没有所谓的'未来'。如果你'此时此刻'没有在跳舞（没有感到充实），这种潜在性运动就是一种人生谎言。"
  V3_exclusivity:
    passed: true
    why_not_common: "反对主流的'延迟满足'和'金字塔式线性人生规划'，主张把过程本身当作结果（现实性运动）。"

- id: s05
  title: 自我接纳与他者信赖 (Acceptance & Trust Calibration)
  type: framework
  V1_cross_domain:
    passed: true
    evidence:
      - 自我心理场景：青年讨厌自己的缺点
      - 人际交往场景：面对可能背叛自己的朋友
      - 社会归属场景：寻找共同体感觉
  V2_predictive_power:
    passed: true
    novel_question: "如何在充满办公室政治的新团队中快速立足？"
    derived_answer: "不要为了融入而去伪装能力（放弃自我肯定，选择自我接纳）；然后单方面地无条件信赖新同事（他者信赖），不附加条件。如果被背叛，那是他人的课题。"
  V3_exclusivity:
    passed: true
    why_not_common: "严格区分了'信用（有条件的信任）'和'信赖（无条件的信任）'，并指出要建立深厚关系必须跨越信用，付出无条件的信赖。"
